# 原型结构与边界

## 本地核心

`crates/pet_core` 产出 Rust 动态库/静态库。Flutter 通过 `dart:ffi` 发送 JSON 请求，在工作 isolate 中执行数据库操作，界面线程不阻塞。

SQLite 通过一个小型 C ABI 封装使用系统 SQLite 库。所有状态修改使用 `BEGIN IMMEDIATE` 事务及参数绑定。数据库版本超出当前支持范围时拒绝打开，不尝试覆盖。当前状态存成一个带版本的 JSON 文档，后续可以通过迁移拆为规范化表。

性格数据通过 `include_str!` 编译进核心；修改 `assets/personas/` 后需要重新构建 Rust 库。目录、卡片和示例仍是独立 JSON，供后续角色编辑器使用。

## 对话事务

1. `prepare_chat` 从真实状态生成上下文，返回请求内容及当前 `revision`，不写入未成功的聊天。
2. Dart 通过本地 `CompanionAgent` 调用 OpenAI Responses，维护有次数和时间上限的函数调用循环，保留本轮完整工具交换。Key 仅在内存中，禁止携带凭据跟随重定向，不直接展示服务商错误正文。
3. 只有得到完整文字回复，才调用 `commit_chat`。核心验证 revision，成对保存用户和角色消息。
4. 请求期间若另一进程修改了性格、记忆或状态，旧回复无法提交。前端保留原输入供用户重试。

应用没有常驻后台推理和自动 API 重试。离线活动直接由本地规则执行；这些活动的预写台词标为「小屋互动」，不会伪装成联网模型回答。

## 性格与记忆

三套性格共用同一角色形象，身份固定为 Alice。切换只影响之后的表达方式。长期记忆由用户主动确认。模型可以提出待确认建议，确认后才落盘；拒绝或失败的本轮建议不会写入记忆。

删除记忆及切换性格会移动 `context_start_id`。历史聊天仍保留在本地，后续提示词只使用新的上下文段；没有独立摘要或向量缓存会把删除的数据重新带回。

## 时间与小游戏

恢复时结算经过的时间，每次最多结算 48 小时，需求有温和下限。系统时间倒退不会倒扣或发放进度。基础互动有 30 秒冷却。找珍珠的答案仅保存在内部存档，不返回到界面快照；一次游戏只结算一次。

## 简洁角色界面

主窗口默认 480×760，只有角色、回应气泡和四个轻互动入口。聊天输入框按需展开，其余功能收进底部面板。`MotionDirector` 统一管理场景优先级：等待远程回复优先显示思考，休息持续到唤醒，短暂动作结束后返回倾听或待机；请求失败和取消都退出思考状态。

三个透明 PNG 图集由内置生图功能生成并原样复制到资源包；Flutter 运行时按网格取帧，不在动画过程中重复解码。角色支持系统减少动画设置，应用进入后台停止动画时钟。

完整 Agent 协议和边界见 [agent-runtime.md](agent-runtime.md)。

## 设备模式（0.4）

`device_mode.dart` 提供设备布局及 `device.json` 外观偏好；`ALICE_DEVICE_MODE` 显式选择全屏／预览，不改变普通桌面透明角色模式。Rust schema 2 新增 satiety、cleanliness、sleeping，迁移与 SQLite user_version 在同一事务内提交。睡眠持续到 wake，离线结算最多 48 小时；喂食／洗澡有冷却、上限，睡着时拒绝这些动作。旧版本会拒绝新版存档。

`wifi.dart` 仅在用户打开 Linux 配网面板时连接系统 D-Bus；扫描按 SSID 原始字节、频段和加密类型分组。5GHz 设置使用 NetworkManager `802-11-wireless.band=a`，2.4GHz 为 `bg`，不合并同名双频网络。密码通过 D-Bus 交给 NetworkManager，不经 shell、SQLite 或模型。成功反馈等待连接 activated，实际系统授权、地区信道与重连仍需真机验证。

`local_library.dart` 复制用户选取的本地音乐，限制大小、数量与格式签名，内容哈希去重并限制 manifest 文件名。`audio_companion.dart` 复用现有音乐／语音音量策略播放导入文件；无自动联网下载、加密音乐解锁或网易云登录。移除只作用于应用副本。

待机仅停止角色动画、显示时钟及覆盖半透明暗层；背光、传感器、BLE/A2DP 仍待实现。`wakeSignal` 为显示唤醒入口，未来传感器应经去抖与权限受限的硬件服务进入；模型不能执行系统命令。当前没有真实传感器连接按钮。

树莓派构建与自启动操作见 README 的 0.4 部分。尚未在 ARM64 真机构建与运行，x64 验证不等于完成树莓派支持。
