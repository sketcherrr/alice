# 0.2 · 透明桌宠与小游戏

## 桌面陪伴

桌面入口启用透明 Flutter 画布和原生透明窗口，取消标题栏、界面渐变、光晕和地面背景。首次选择性格后，回应气泡停留约 8 秒，操作条在鼠标离开后自动收起；闲置时只绘制角色。

- 单击：摸摸；双击：打开聊天。
- 拖动人物：移动窗口；右键或长按：打开抽屉。
- 鼠标停在人物上：显示聊天、摸摸、喝茶、休息、伸懒腰和抽屉入口。
- 抽屉包含记忆、历史、性格、三种小游戏、置顶开关和退出。
- 窗口平时为 360×520，聊天和面板展开至最多 500×780，并限制在当前屏幕工作区内；关闭后缩回。

macOS 使用透明 NSWindow 与 FlutterViewController；Linux 使用 GTK RGBA visual 和透明 FlView；Windows 使用无边框窗口与透明 DWM 合成。Linux 需要桌面合成器支持透明；Wayland 的移动/置顶最终由 compositor 决定。此版没有承诺逐像素鼠标穿透，人物附近的透明区域仍可能接收鼠标事件。

Windows 的原生窗口编译检查与 Windows 发行包是两件事：当前仍需完成 Rust/SQLite 运行库分发后才能交付 Windows 安装包。手机继续保留原来的小屋布局。

## 动画

8 种动作、56 个实际图集帧：待机、挥手、开心、喝茶、睡眠、伸懒腰各 8 帧；倾听和思考各 4 帧。动作切换有 180ms 淡入衔接，运行时补充轻微呼吸、倾斜及开心/伸懒腰的小特效。空闲约 55 秒会伸个懒腰，聊天、思考和睡眠时不插入空闲动作。尊重系统减少动画设置，应用隐藏后停止动画时钟。

新版素材由内置 image_gen 生成，RGBA 原像素与透明通道保持原样，未覆盖旧素材：

- `assets/characters/alice/animations/idle-v2.png`：待机、挥手。
- `assets/characters/alice/animations/social-v2.png`：开心、伸懒腰。
- `assets/characters/alice/animations/rest-v2.png`：喝茶、睡眠。

完整提示词和网格定义在 [generation-v2.json](../assets/characters/alice/animations/generation-v2.json)。透明区域已通过实际 Flutter 渲染的 alpha 检查。

## 小游戏

从抽屉打开，全部离线运行，不调用 API。

| 游戏 | 操作与规则 |
|---|---|
| 找珍珠 | 保留原玩法，选择藏着珍珠的贝壳 |
| 俄罗斯方块 | ← → 移动，↑ 旋转，↓ 下降，空格直接落下，C 暂存，P 暂停；七袋随机、落点预览、消行计分与逐渐加速 |
| 打砖块 | 鼠标、拖动或 ← → 控制挡板，空格/点棋盘发球，P 暂停；3 条生命、3 关，后两关有需要两次击中的砖 |

两种新游戏都有屏幕按钮、暂停和重开。应用失去焦点、隐藏或进入后台时自动暂停，回来后需主动继续。关闭游戏面板结束当前局，进行中的棋盘不跨重启恢复。完成局的最高分、上一局分数与次数通过 Rust/SQLite 保存；重复的局 ID 不重复记录。退出未完成的局不会计成绩。

## 验证入口

- `dart scripts/check-arcade.dart`：独立规则检查，不需要 Flutter 测试服务或网络。
- `cargo test --locked`：包含成绩持久化、重复提交和无效参数检查。
- `flutter test`：包含游戏界面/键盘/暂停/生命周期及桌面透明像素与面板检查。
- `lib/smoke_desktop.dart`：无界面 Flutter 引擎截图与真实 Rust 核心检查入口，不进入 release 应用。
